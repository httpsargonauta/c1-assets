## 📌 ¿Cómo obtener el enlace de cualquier foto nueva que subas?

Cuando agregues una nueva imagen en este repositorio, su enlace directo siempre seguirá esta estructura:

### Enlace directo estándar:
```text
https://raw.githubusercontent.com/httpsargonauta/c1-assets/main/<carpeta>/<archivo.png>
```

### Enlace CDN de alta velocidad:
```text
https://cdn.jsdelivr.net/gh/httpsargonauta/c1-assets@main/<carpeta>/<archivo.png>
```
